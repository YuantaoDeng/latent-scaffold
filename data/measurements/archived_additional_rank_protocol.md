# Additional models under the current source-selected rank rule

This protocol supersedes the old rank-8 cross-model PCA-superiority gate. Full evaluation order is MobileNetV3-Small, RegNetX-002, EfficientNet-B0, with their already cached pretrained weights. The latter two were reordered based on observed EfficientNet runtime, before observing either model's target outcomes; preserve the original protocol and the order amendment in the results directory. EfficientNet's prepared source trajectory remains available. Evaluate CIFAR-100 then CIFAR-10 for each; independent source preparation can overlap to reduce waiting, with each dataset's rank frozen before its target evaluation. Source orders, target orders, optimization seeds, training settings, anchors, random controls and bootstrap procedures match the completed ResNet/DeiT experiments. Associated architecture and pretrained weights both change; this is not an isolated architecture intervention.

Before target evaluation, set k=r to the smallest rank in 8..32 with positive mean source-order-held-out future-drift coverage gain over construction-matched Representation PCA. Never use one-SE or maximize target performance. If no eligible rank exists, report that outcome and do not invent a fallback. Reuse completed trajectories; replay missing checkpoint states or actual updates only with numerical parity checks. All active response covariances use 16 paired Gaussian encoder-parameter directions, relative step 1e-4, FP32 evaluation, and fixed checkpoint buffers. BatchNorm-buffer contributions remain separately measured for actual optimizer updates.

The sequence trainer's auxiliary per-trajectory rank remains 8 and does not constrain weight training. All final source pooling, response subspaces, target projections, matched random/PCA controls and frozen-readout analyses are rebuilt at the selected k=r using the saved full drift matrices and covariances. Use the selected-rank analysis directory for current results, not auxiliary generation-time `runs.csv` scores.

Preserve the full checkpoint curve (0..4 for CIFAR-100, 0..5 for CIFAR-10), individual and pooled overlaps, energy coverage, temporal transfer, matched random/PCA controls, actual updates and frozen logit/loss readout. Fixed scaffolds always derive from source 1→2 drift. PCA superiority is a source selection criterion, not a required substantive claim.

For an explicit stopping rule, a model matches the current ResNet pattern only if both datasets have positive lower nominal 95% bootstrap bounds for all temporal matched-random gains, checkpoint 2 and final overlap increases from initialization, learned-response transfer, actual-update random gain, and frozen-logit random gain. CIFAR-100 additionally requires positive frozen-loss gain; CIFAR-10 loss is reported separately because the current ResNet result is uncertain. Failure of this conservative gate does not prove absence of the phenomenon. Report each component, every attempted model, and all negative or incomplete outcomes. Stop at the first model satisfying the fixed gate on both datasets. This sequential search is exploratory: nominal intervals are not corrected for searching architectures, and the selected model is not a fresh confirmatory replication.

Results: `results/additional_rank_rule/`; runner: `additional_rank_models.py`. Existing model experiments and manuscript remain intact.
